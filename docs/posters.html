Traceable Design Agent · eval

Does the agent earn its cost?

Two ways to ask a model for designs, three models, seven cases (three of them with traps). llm: one call with the requirements. agent: the same model in a loop that can run the physics check before it answers.

The oracle is a brute-force search over every design in a case, up to 17,000 of them. It finds the true lightest part that passes, so every answer can be scored: regret = how much heavier the chosen part is.
The first eval said a model beat the optimum. That is impossible, so the bug was in my reference: it only tried whole-millimetre widths. Fixed it, re-scored the saved runs, no new model calls.
The verifier is not optionalA strong model made a confident 3x error in 1 of 4 runs. You cannot tell which run in advance, so every run is checked.
The loop buys reliability, not lighter partsThe agent never produced a false pass. With the strongest model the loop costs 1.6x for 0.2% less mass.
Cheap model + tool is the trade to measureHaiku with the tool: every proposal verified, 1/13 the cost of Opus, 2.6% heavier. For 500-option sweeps, that is the next test.
One run per configuration, seven toy cases. Signals worth testing at scale, not conclusions. 2 / 2
